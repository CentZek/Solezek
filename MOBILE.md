# Mobile App Roadmap (Android & iOS)

The app is built mobile-first as a PWA so it can ship as a website today and be
wrapped for the App Store / Play Store later with **Capacitor** (recommended over
a React Native rewrite — the whole React codebase carries over unchanged).

## Already implemented (web/PWA layer)

### iOS requirements & guidelines
- `viewport-fit=cover` + `env(safe-area-inset-*)` — layout respects the notch and home indicator (`safe-top` on screens, bottom inset on the nav bar)
- PNG `apple-touch-icon` (180×180) — iOS ignores SVG icons; generated by `scripts/generate-icons.mjs`
- `apple-mobile-web-app-capable`, status-bar style, app title — full "Add to Home Screen" standalone support
- `100dvh` instead of `100vh` — no layout jumps when Safari's toolbars show/hide
- `touch-action: manipulation` + no tap highlight — no 300ms delay, no double-tap zoom, no gray flash
- Text inputs are ≥16px — iOS does not auto-zoom on focus
- Touch targets ≥48px (Apple HIG minimum is 44pt)
- Speech synthesis hardened for iOS Safari (`resume()` on paused synth, try/catch, works only after user gesture by design)
- `prefers-reduced-motion` respected, plus an in-app reduced-motion toggle (accessibility guideline)
- No hover-dependent interactions; everything works with touch
- Offline-first: service worker precaches the whole app incl. self-hosted fonts

### Android
- Maskable + regular PNG icons (192/512) with safe-zone padding
- `display: standalone`, portrait orientation, theme color
- Same offline behavior via the PWA service worker

### Architecture kept mobile-ready
- All platform APIs behind small wrappers: `src/audio.ts` (speech/sounds/recognition), `src/state/progress.ts` (storage) — swap implementations for Capacitor plugins without touching screens
- `HashRouter` — works from `file://` / Capacitor's local scheme with no server routing
- Content is pure data (`src/content/levels/`) — ships inside the app bundle, no network needed
- No browser-only APIs in game logic

## Still needed for store submission (later)

1. **Capacitor wrap**
   ```bash
   npm install @capacitor/core @capacitor/cli
   npx cap init   # webDir: dist
   npx cap add ios && npx cap add android
   ```
2. **iOS specifics**
   - Xcode project: bundle id, signing team, deployment target (iOS 14+)
   - App icon set in Assets.xcassets (use `public/icon-512.png` as the source; all sizes generated in Xcode)
   - Launch screen (storyboard or `UILaunchScreen` with the brand color `#2F9E5F`)
   - `NSMicrophoneUsageDescription` in Info.plist — required for the speaking practice
   - Speech recognition: the Web Speech API is **not available in WKWebView** — use `@capacitor-community/speech-recognition` behind the existing `createSpeechRecognizer` wrapper
   - App Store review: the app must not be "just a wrapped website" — native splash, offline content (done), and native speech/haptics plugins address this
3. **Android specifics**
   - Adaptive icon (maskable PNG already provided)
   - `RECORD_AUDIO` permission for speaking practice
4. **Backend** — Supabase auth + progress sync (schema mirrors `src/state/progress.ts`), server-side validation of XP/exam scores per the master prompt's security section
5. **Optional native polish** — haptics on correct answers, native share, push reminders for streaks
