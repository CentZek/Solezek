# MASTER CURRICULUM PROMPT

## Extend the Bahdini → English Basic English Course from Level 21 to Level 40

Continue developing the Bahdini-first English learning application.

The first 20 levels established the learner's foundation:

* greetings
* introductions
* numbers
* colors
* family
* home
* objects
* food
* shopping
* time
* daily routines
* places
* transportation
* clothes
* weather
* actions
* basic questions
* basic conversations
* basic English challenge

Now create **20 additional levels: Levels 21–40**.

These levels should NOT simply introduce more vocabulary.

The learner should now begin to transition from:

> "I recognize English words."

to:

> "I can actually communicate in simple English."

The progression should move approximately from:

**A1 foundation → strong A1 → early A2**

Use the vocabulary from Levels 1–20 repeatedly, combining it with the new material.

Every level must continue to use the same learning structure:

1. Introduction
2. Exercise Round 1
3. Exercise Round 2
4. Level Exam
5. Reward
6. Review / weak-word reinforcement

However, the games and scenarios should become progressively more realistic.

---

# IMPORTANT PEDAGOGICAL PRINCIPLE

The objective is not to teach the largest number of words.

The objective is to make the learner able to **use a relatively small vocabulary extremely well**.

For example, instead of teaching 30 new verbs at once, teach 8–12 useful verbs and make the learner use them in:

* statements
* questions
* negatives
* past tense
* future tense
* conversations
* listening
* sentence building
* real-world scenarios

The application should repeatedly recycle vocabulary.

A word learned in Level 4 should potentially appear again in Level 24, 29 and 35.

This is intentional spaced repetition.

### Examples

### Introduction

Use pictures.

🍕 I like pizza.

☕ I like coffee.

🥦 I don't like broccoli.

The learner hears the sentence.

### Exercise Round 1

**Like / Don't Like Game**

Show pictures.

The learner selects:

👍 I like it.

👎 I don't like it.

Then convert the choice into English.

### Exercise Round 2

**Sentence Builder**

I / coffee / like

→

I like coffee.

Then:

I / don't / coffee / like

→

I don't like coffee.

### Exam

Mix:

* listening
* sentence building
* picture interpretation
* choosing correct sentence
* simple personal preference questions

The learner should finish the level able to talk about basic preferences.

# 11. HINT SYSTEM

Do NOT immediately show the answer.

Use progressive hints.

### Hint 1

Show a picture.

### Hint 2

Highlight important word.

### Hint 3

Show first letter.

### Hint 4

Show Bahdini meaning.

### Hint 5

Show the answer.

This encourages learning instead of guessing.

---

# 12. ERROR LEARNING

Every incorrect answer should be recorded.

Then create 5 new questions using those words.

This should happen automatically.

# 18. DO NOT MAKE EVERYTHING MULTIPLE CHOICE

This is extremely important.

Multiple choice is easy to build but does not necessarily produce strong learning.

Across each level, mix:

* recognition
* recall
* listening
* sentence construction
* matching
* speaking
* ordering
* contextual decisions
* conversation

The learner should sometimes have to **produce** the answer.

---

Introduce questions where the learner must remember the answer.

🍎

# 20. CONVERSATION ENGINE

Each conversation should contain:

correct response

explanation

next dialogue node

Example structure:

```text
Conversation
 ├── Node 1
 │    ├── Character message
 │    └── Choices
 │
 ├── Node 2
 │    ├── Character message
 │    └── Choices
 │
 └── Node 3
      └── Completion
```

This will allow hundreds of future conversations to be created without rebuilding the game.

# 21. PRACTICAL ENGLISH OVER PERFECT ENGLISH

Teach phrases that learners will actually use.

For example:

"I'd like..."

"Can I have...?"

"How much is it?"

"Where is...?"

"Can you help me?"

"I don't understand."

"Can you repeat that?"

"Please speak slowly."

These phrases are extremely valuable for someone travelling or working in an English-speaking environment.

# MOST IMPORTANT PRINCIPLE

The first 20 levels taught the learner:

**"What does this English word mean?"**

Levels 21–40 must increasingly teach:

**"How do I use this English?"**

By the end of Level 40, a motivated learner who started with almost no English should be able to handle simple everyday situations such as:

* introducing themselves
* talking about family
* talking about likes and dislikes
* describing people
* describing places
* explaining where something is
* talking about what they are doing
* talking about yesterday
* talking about tomorrow
* buying something
* ordering food
* asking for directions
* taking a taxi
* navigating an airport
* checking into a hotel
* having a basic workplace conversation
* explaining a simple problem
* understanding simple spoken English

The application should achieve this through **repetition, active recall, listening, speaking, games, contextual learning and progressively reduced Bahdini support**.

The goal is not for the learner to finish 40 levels.

The goal is for the learner to finish Level 40 and realize:

# "I can actually speak some English now."

Build the curriculum and game system around that outcome.
