# MASTER DEVELOPMENT PROMPT

## Build an Interactive English Learning Platform for Kurdish Bahdini Speakers

Build a modern, highly interactive web application that teaches **English to native Kurdish Bahdini speakers**, starting from absolute beginner level.

The application should eventually be suitable for conversion into a **native Android and iOS application**, so the architecture, UI components, game mechanics, content model and data structure must be designed with mobile-first principles from the beginning.

The product should feel like a combination of:

* Duolingo — playful, addictive, game-based learning
* Busuu — structured progression, CEFR-aligned learning and checkpoint testing
* British Council LearnEnglish — practical vocabulary, pronunciation, grammar and real-world English
* A children's educational game — visual, friendly, rewarding and easy to understand

Do NOT simply copy any existing application's design, branding, characters or copyrighted content.

Instead, take inspiration from the learning mechanics and create an original **Bahdini → English learning experience**.

---

# 1. CORE PRODUCT CONCEPT

The learner is a Kurdish Bahdini speaker who wants to learn English.

The application should teach:

**Bahdini → English**

rather than:

**English → English**

especially during the beginner stages.

Every new English word should initially be supported by:

1. English word
2. Bahdini meaning
3. Picture/visual
4. Audio pronunciation
5. Example sentence
6. Optional phonetic pronunciation
7. Interactive practice

Example:

### English

**APPLE**

### Bahdini

**سیڤ**

### Audio

🔊 Apple

### Example

**I eat an apple.**

### Bahdini explanation

A short, natural Bahdini explanation.

The learner should progressively move from:

**Bahdini + English**

to:

**Mostly English**

to:

**English only**

as their level improves.

---

# 2. TARGET USER

Primary audience:

* Kurdish Bahdini speakers
* Absolute English beginners
* Children, teenagers and adults
* Users who may have little or no formal English education

The application must therefore be:

* extremely simple
* visual
* intuitive
* encouraging
* non-intimidating
* highly repetitive
* game-like
* usable by people with limited English knowledge

Avoid complicated English explanations in early levels.

---

# 3. LANGUAGE

The interface should support:

### Primary learning language

**Kurdish Bahdini**

### Target language

**English**

The application should be designed so that all educational content can later be stored in a database with:

* English
* Bahdini
* pronunciation
* audio
* example sentence
* example translation
* image
* category
* difficulty
* grammar concept

Do not hard-code educational content directly into UI components.

Create a scalable content structure.

---

# 4. IMPORTANT: BAHHDINI QUALITY

Do NOT automatically translate English sentences word-for-word into Kurdish.

Bahdini translations should sound natural to a Bahdini speaker.

Create a content architecture where Bahdini translations can be reviewed and corrected by a native Bahdini speaker later.

Every vocabulary item should support:

```text
english_word
bahdini_translation
english_pronunciation
audio_url
image_url
example_sentence
bahdini_example
category
difficulty
part_of_speech
```

Every lesson should support:

```text

exercises

difficulty
level
```

# 5. COURSE STRUCTURE

Create a complete **Basic English Course** containing at least:

# 20 LEVELS

Each level must follow the same fundamental learning cycle:

## STEP 1 — INTRODUCTION

Introduce the vocabulary and/or grammar concept.

## STEP 2 — EXERCISE ROUND 1

Practice the new material using several game types.

## STEP 3 — EXERCISE ROUND 2

More difficult practice with different game mechanics.

## STEP 4 — LEVEL EXAM

Test whether the learner actually understands the material.

## STEP 5 — REWARD

If passed:

* XP
* coins
* badge
* level completion
* progress animation
* unlock next level

If failed:

Do not punish the learner.

Instead:

* show mistakes
* explain them in Bahdini
* recommend specific review exercises
* allow another attempt

# 10. GAME FEEDBACK

Every answer should provide immediate feedback.

Correct:

✅ Great!

🎉 Excellent!

⭐ +10 XP

Incorrect:

❌ Not quite.

Never shame the learner.

Do not make mistakes feel like failure.

Use:

"Let's try again."

"Wrong!"

# 23. GRAMMAR

Grammar should be taught indirectly at first.

Do NOT give beginners large grammar lectures.

Instead:

Teach patterns.

Example:

I am Ali.

I am happy.

I am tired.

Then explain:

"I" + "am"

Later introduce:

You are.

He is.

She is.

This allows learners to recognize the structure naturally.

As levels progress, provide small Bahdini explanations.

# 51. COURSE PROGRESSION

The 20 levels should have increasing complexity.

Levels 1–5:

Mostly vocabulary + recognition.

Levels 6–10:

Vocabulary + simple sentence patterns.

Levels 11–15:

Vocabulary + grammar + short conversations.

Levels 16–20:

More listening + sentence construction + real-world situations.

Do not suddenly increase difficulty.

Each level should reuse approximately 20–40% of earlier vocabulary where useful.

This creates natural spaced repetition.

---

# 52. IMPORTANT: CONTENT QUALITY

Before considering the course complete, review every level.

Check:

1. Is the vocabulary genuinely useful?
2. Is the English correct?
3. Is the Bahdini translation natural?
4. Does the difficulty increase gradually?
5. Are old words being reused?
6. Are there enough exercises?
7. Is listening included?
8. Is sentence construction included?
9. Does the exam test the lesson?
10. Does the learner understand why an answer is correct?
11. Does the lesson feel fun?
12. Does the lesson work on a phone?

Do not generate 20 levels and stop.

Iterate through the entire course and improve it.
